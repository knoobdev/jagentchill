JAgentChill — UI design reference

Static reference for the cross-platform video editor with a chat agent, a one-prompt video workflow and a film studio. Tokens and components follow openspec/changes/build-jagentchill/specs/design-system; screens follow the capability specs named under each frame. Thumbnails are CSS gradients, text content is illustrative, provider and model names are fictional examples. The theme toggle switches the token variables for every frame at once.

Foundations

Token names and values are those of design-system (requirements Colour tokens, Editor colour tokens, Typography tokens, Spacing, radius and border tokens, Elevation tokens, Motion tokens, Icon tokens, Control size tokens and density rules). CSS custom properties replace “/” with “-” (bg/app → --bg-app). Each swatch pair shows light then dark.
