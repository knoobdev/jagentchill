# Tasks — build-jagentchill

Every requirement of every capability is covered by exactly one task below. A task is done only when: the behaviour of each
listed requirement is implemented in full on web, desktop and mobile (no stub, no placeholder screen, no "later"); every
scenario of those requirements is an automated test that passes; screens match `docs/design/jagentchill-ui.html` where a frame
exists; and the owning check was run for real (unit tests, plus the browser or device run for UI, plus the live run against the
Gateway for host features). Spikes named by a requirement are run before the task that depends on them.
